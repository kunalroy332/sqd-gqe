# Data of the study

Result files of the runs behind the manuscript, as produced by the scripts in `scripts/analysis/`. Nothing here is regenerated by
the analysis; the analysis reads it. No credentials, host names or user names are stored in these files.

| Folder | Contents | Used by |
|---|---|---|
| `hf/`, `tuned/` | The zero-shot inference campaign of the two training configurations (Hartree-Fock penalty, tuned reward): 44 runs each | `headline_numbers.py`, `three_way_load.py`, `make_html_sets.py`, `divergence_tables.py`, `inference_timing.py` |
| `training/` | Per-iteration histories of the Stage-1 and Stage-2 trainings (`t2_s1_*`, `t2_s2_*` no penalty, `t2p_s2_*` Hartree-Fock penalty, `t2t_s2_*` tuned reward), with the tracked chemistry of every iteration | `make_html_sets.py`, `compare_trainings.py`, `timing_summary.py`, `chem_figures.py` |
| `ibm/` | Inventory of the IBM Quantum jobs (billed QPU seconds), the `ibm_kobe` calibration snapshots and the per-job usage of the logs | `qpu_training_numbers.py`, `make_cost_section.py`, `make_calibration_table.py` |
| `R3.pkl` | The pairing of the two configurations over the 43 shared test cases; rebuilt by `scripts/analysis/circuit_analysis/three_way_load.py` | `headline_numbers.py`, `make_html_sets.py` |

Inside `hf/` and `tuned/` (one file per run unless stated):

| Sub-folder | Contents |
|---|---|
| `data/` | The ten sampled circuits of the run: token sequence, transpiled depth and two-qubit-gate count, valid-shot and spin-resolved excitation statistics, IBM job id |
| `rerank/` | Ranking energy of each circuit (one-shot diagonalization, 200 strings per spin sector) |
| `rerecovery/` | Result of each recovery (best, second, merged and the two E+D picks): energy, 25-step history, singles-injected energy, excitation histogram |
| `selection_batch1.json` | The circuits chosen by the ranking, for each run |
| `divergence/` | Ideal fidelity, Hellinger and Jensen-Shannon distances to the LUCJ state (32, 38 and 44 qubits only) |
| `vocab/` | The operator pool of each target molecule: token id to operator and angle |
| `connectivity/` | Qubits touched and connected pairs of the logical and transpiled circuits |
| `qpu_fresh.json`, `timing_sacct*.psv` | Billed QPU time of the sampling jobs; Slurm elapsed times of the inference jobs |

The raw measurement counts and the transpiled circuits of the hardware jobs are not included (they are large); the sampled gate-token
sequences are, so that every circuit can be rebuilt and submitted again (`scripts/analysis/circuit_analysis/resample_raw_counts.py`).
